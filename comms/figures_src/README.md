# Figure sources

Every figure in the report and deck is generated by a script in this folder.
Sources are edited; rendered outputs are never edited by hand.

Outputs are written to `../figures/` as PDF (vector, for LaTeX/Word) and
300 dpi PNG (for slides).

## Requirements

    pip install matplotlib numpy shapely

## Rebuild everything

    cd comms/figures_src
    python fig1a_machine.py
    python fig1b_abstraction.py
    python make_skeleton.py
    python make_skeleton_3d.py

## Shared engine: layout.py

- `Placer`  - collision-aware text placement. Obstacles are true polygons
  (shapely), so labels may use the concave space beside diagonal members.
- `Callouts` - numbered discs plus a key column, for dense drawings where
  long text labels cannot lay out cleanly.
- `audit(...)` - independent check: label-label overlap, label-on-geometry,
  clipping. Every script prints its audit line when it runs.

**A non-zero audit count means the layout regressed. Fix it before committing
the rendered output.**

## palette_check.py

Colours are assigned by role (bodies, ropes, motion, frames, construction).
This script converts each role colour to CIE Lab and reports pairwise dE.
Keep every pair above dE 24 so hues stay distinguishable in print.

## Notes on the physics drawn in fig1a_machine.py

- The rope meets the boom-point sheave at true tangent points and wraps the rim.
- The dipper bail is a two-force member: it is pinned at the dipper lugs and
  loaded only at the rope socket, so it aligns with the rope. Bail direction and
  rope tangent are coupled, and are solved by fixed-point iteration - not placed
  by eye. alpha_3 is therefore an output of the geometry, not a chosen value.
